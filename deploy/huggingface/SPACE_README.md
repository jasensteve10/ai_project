# Electoral Text-to-SQL with retrieval (public demo)

French questions about Côte d'Ivoire's 2025 legislative election results, answered by
retrieval over schema, definition and place cards and read-only SQL on DuckDB.

**This public demo makes no calls to a language model.** Typed questions return the
context each retrieval mode (BM25, E5, hybrid, or none) would give the SQL generator.
The sidebar replays answers generated by Claude Haiku 4.5 in the archived evaluation
(30 September 2026) for the 18 development questions, with their SQL, results and
evaluation outcome.
